Getting started

Kipuu for Windows

Get your company's files as a folder in File Explorer. Files download only when you open them, so they don't fill up your PC.

Kipuu for Windows adds a Kipuu folder to the left side of File Explorer, next to your other drives. You see every file and folder of your company with its name and size, and each file downloads the moment you open it. It works on Windows 10 and Windows 11.

Install it

  1. On your Windows PC, open kipuu.com, select Download at the top and choose Kipuu for Windows.
  2. Open the file you downloaded. You don't need to be an administrator. If Windows shows a protection notice, select More info and then Run anyway.
  3. When it finishes, sign in with your Kipuu email and password. If your account uses two-step verification, enter your code.
  4. Kipuu appears on the left side of File Explorer and as an icon next to the clock. From then on it opens by itself when you turn on your PC.

Work in the folder

  1. Open a file: it downloads and opens like any other file on your PC.
  2. Add a file: copy or drag it into a Kipuu folder. In about a minute your team sees it on the web and on their phones.
  3. Large files, like long videos, upload in pieces, several at a time. If the internet drops or you turn off your PC, Kipuu picks up where it left off the next time it connects, without starting over.
  4. Rename a file or folder: the new name is saved in Kipuu right away, for everyone.
  5. Delete a file or folder: it goes to the Kipuu trash, where you can restore it from the web.
  6. To keep a file on your PC even without internet, right-click it and choose Always keep on this device. To make room again, choose Free up space.

Drag a file to another Kipuu folder and it moves in Kipuu too. If a change can't be saved, for example without internet, File Explorer keeps the file as it was and the Kipuu icon next to the clock tells you why, so nothing changes without you knowing.

The icon next to the clock

Hover over it to see whether Kipuu is up to date, syncing or offline. Click it to open your Kipuu folder. Right-click it to open Kipuu on the web, turn off starting with Windows, sign out or quit.

To uninstall, go to Settings, then Apps, and remove Kipuu. The files you kept on your PC stay in your folder, and everything in Kipuu stays in Kipuu.
